\subsection{Quản lý tài liệu}
Công cụ tài liệu: Microsoft Word, Microsoft Excel, Google Docs/Sheets/Slides.\\

Mã nguồn được quản lý bằng Git trên GitHub, tuân theo quy ước nhánh: \texttt{main}, \texttt{develop}, \texttt{feature/*}, \texttt{report}, \texttt{chapters/ch1..ch5}.
